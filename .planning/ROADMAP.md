# Roadmap: SuperPrecios QRO

## Phase 1: Guided anonymous checkout

**Goal:** The shopper can enter a minimal local profile and complete an informed official-store
handoff without losing their basket.

**Requirements:** PROF-01 to PROF-03, HAND-01 to HAND-04, CONT-01 to CONT-03.

**Deliverables:** profile state module, checkout readiness UI, safe state migration, browser
acceptance verification, and a database migration design that is not activated without credentials.

## Phase 2: Verified price operations

**Goal:** Add trusted price and store-coverage data only after a compliant source and operating
owner are confirmed.

**Requirements:** DATA-01 to DATA-02.

## Phase 3: Optional account sync

**Goal:** Allow account-backed plans across devices with explicit consent and data retention rules.

**Requirements:** DATA-03.
